# Smart Petrol Cost Calculator with BUDI MADANI Rebate

## Introduction

This application was developed for the ICT602 Mobile Technology assignment. The system helps users calculate petrol costs and estimate savings through the BUDI MADANI subsidy.

## Features

### Home Page

* Select petrol type (RON95, RON97, Diesel)
* Enter petrol price per liter
* Enter fuel usage
* Select BUDI MADANI eligibility
* Calculate total petrol cost
* Display rebate amount
* Display total savings

### About Page

* Application information
* Author information
* Matric number
* Course information
* GitHub repository link

## How to Use

1. Select the petrol type.
2. Enter the petrol price per liter.
3. Enter fuel usage in liters.
4. Select BUDI MADANI eligibility.
5. Click the Calculate button.
6. View the calculation result.
